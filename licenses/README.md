# Licence Texts

Full texts of the licences covering **MPVX Player** and its bundled open-source components.
See [`../THIRD-PARTY-NOTICES.md`](../THIRD-PARTY-NOTICES.md) for the component breakdown.

- `../LICENSE`: **GNU GPL v3.0** — MPVX Player application source
- `LGPL-2.1.txt` / `GPL-2.0.txt`: libmpv & FFmpeg native playback/decoder engines
- `MIT-MpvAndroid.txt`: libmpv Android JNI bindings (`mpvlib.aar`)
- `ISC-Libass.txt`: libass native SSA/ASS subtitle renderer
- `MIT-Anime4K.txt`: Anime4K real-time upscaling GLSL shaders
- `Apache-2.0.txt`: AndroidX Media3, Jetpack Compose, AndroidX, Material Components, Coil, OkHttp, SMBJ, Apache Commons Net, ZXing, chardet4j, Reorderable, `ass-kt` / `ass-media`
- `BSD-3-Clause.txt`: JSch (SFTP) and NanoHTTPD (local range-streaming bridge)
